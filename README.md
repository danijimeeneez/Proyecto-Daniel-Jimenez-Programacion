
# Academia de Criaturas

## 1. ¿En qué consiste?

**Academia de Criaturas** es un videojuego de aventuras por consola desarrollado en Java e inspirado en los juegos de Pokémon.

El jugador comienza eligiendo una criatura inicial y se embarca en una aventura por la región de Valthera. Durante el recorrido podrá explorar diferentes lugares, encontrar nuevas criaturas, conseguir objetos, mejorar su equipo y enfrentarse a distintos entrenadores.

El objetivo principal es conseguir las dos medallas de gimnasio y derrotar a Damián, el rival del protagonista, en el combate final para completar la aventura.

## 2. Objetivo del juego

El objetivo es avanzar por la historia, conseguir criaturas cada vez más fuertes y preparar un equipo adecuado para superar los diferentes combates.

Para completar el juego será necesario:

- Elegir una criatura inicial.
- Explorar las diferentes zonas de la región.
- Encontrar y conseguir nuevas criaturas.
- Entrenar al equipo mediante combates y experiencia.
- Conseguir las dos medallas de gimnasio.
- Derrotar a Damián en el combate final.

## 3. Características principales

- **Elección inicial:** posibilidad de elegir entre Charmander, Squirtle y Bulbasaur.
- **Exploración:** diferentes lugares para visitar, como bosques, ruinas y cuevas.
- **Encuentros:** posibilidad de encontrar nuevas criaturas durante la aventura.
- **Combates:** enfrentamientos contra entrenadores, líderes de gimnasio y rivales.
- **Tipos y ataques:** las criaturas tienen diferentes tipos, estadísticas y ataques.
- **Experiencia y niveles:** las criaturas pueden ganar experiencia y subir de nivel para mejorar sus estadísticas.
- **Tienda:** permite comprar caramelos utilizando las monedas conseguidas durante la aventura.
- **Inventario:** permite consultar los objetos disponibles.
- **Centro Pokémon:** permite recuperar la vida de las criaturas.
- **Historia:** el jugador avanza por diferentes etapas hasta llegar al enfrentamiento final.

## 4. Cómo jugar

El juego funciona mediante un sistema de menús y opciones en la consola. El jugador tendrá que introducir números o responder a diferentes preguntas para tomar decisiones y avanzar en la historia.

Para jugar, hay que abrir el proyecto en un entorno compatible con Java, como Visual Studio Code, y ejecutar la clase principal `Juego`.

También se puede ejecutar desde una terminal, situándose en la carpeta principal del proyecto:

```bash
javac -d bin src/Juego.java
java -cp bin Juego
```

Es necesario tener instalado el JDK de Java para poder compilar y ejecutar el programa.

## 5. Tecnologías utilizadas

- **Java:** lenguaje utilizado para desarrollar el videojuego.
